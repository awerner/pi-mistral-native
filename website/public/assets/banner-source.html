pi-mistral-native — README banner proposals

Three variants on a 1200 × 400 (3:1) canvas, each shown inside a simulated README on a dark (#0d1117, GitHub dark) and a light (#ffffff, GitHub light) canvas. Mistral's block language — discrete hard-edged rectangles, near-zero radius, staggered entrances — with their orange ramp remapped to a five-step blue ramp. Motion is an enhancement: every variant reads complete as a static image.

Variant A — Animated block hero

Rationale: the block-π mark (π built from discrete Mistral-style blocks, signature blue as the widest top bar) falls in with Mistral's staggered settle animation; a slow ambient blue wash and a pulsing sky dot keep the canvas alive. One dark asset with its own background, so the identical banner works on light and dark READMEs.

SVG · 1200 × 400 · 3:1 Own background — one asset, theme-safe Motion: fall-in · stagger 60ms · ambient wash 64s

Design tokens — blue block system

Derived by cool-hue mapping Mistral's five-step logo ramp (#FFAF01 → #C4001D) while preserving the lightness descent and the "one wide signature bar" structure. These tokens are the handoff for the documentation website (Astro/Starlight).

Ultramarine#0B3FB0Dark ramp base, feet blocks
Ink#101826Dark surface, text on light (harmonizes with GitHub dark #0d1117)
