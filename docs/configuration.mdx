# Configuration keys

import { Badge } from '@site/components';

Every key of `mistral-native.json`, grouped by section. All sections and keys are optional; an absent key is unset and falls through to lower-precedence layers.

Every settable key accepts both `/mistral set <key> <value>` (user scope) and `/mistral set --project <key> <value>` (project scope, trusted projects only).

## `serverTools`

### `serverTools`

Enabled Mistral built-in server-side tools, sent with every chat request.

- **Type:** array of strings
- **Allowed values:** `web_search`, `web_search_premium`, `image_generation`, `code_interpreter`
- **Default:** unset
- **Environment variable:** `MISTRAL_SERVER_TOOLS` (comma or space separated; unknown values are ignored)
- **Set with:** `/mistral set serverTools image_generation` (comma-separated replaces; `+entry` appends, `-entry` removes, a bare key clears)

```json
{ "serverTools": ["image_generation"] }
```

Only `image_generation` runs in chat completions; the other three are dropped with a warning at the next session start. See [Use a Mistral agent](/how-to/use-a-mistral-agent/) · [Server-side and client-side tools](/concepts/tools/)

## `connectors`

### `connectors`

Connector ids or names whose tools are sent with every chat request.

- **Type:** array of strings
- **Default:** unset
- **Environment variable:** `MISTRAL_CONNECTORS` (comma or space separated)
- **Set with:** `/mistral set connectors notion` (comma-separated replaces; `+entry` appends, `-entry` removes, a bare key clears)

```json
{ "connectors": ["notion", "8b6b3f2e-9f4a-4a1e-9c1e-0a2b3c4d5e6f"] }
```

See [Enable connectors and connector tools](/how-to/enable-connectors/)

## `agentId`

### `agentId`

The agent id that switches chat requests to Mistral's Agents API.

- **Type:** string
- **Default:** unset (trimmed; empty after trimming is unset)
- **Environment variable:** `MISTRAL_AGENT_ID`
- **Set with:** `/mistral set agentId my-agent`

```json
{ "agentId": "my-agent" }
```

The value supports the config-value protocol (`$VAR`, `${VAR}`, `!command`). See [Use a Mistral agent](/how-to/use-a-mistral-agent/) · [Keep secrets out of the config file](/how-to/keep-secrets-out-of-the-config-file/)

## `endpoint`

### `endpoint.region` <Badge text="Region-aware" />

Selects the Mistral API region for chat requests and the model catalog.

- **Type:** `"global"` | `"eu"` | `"us"`
- **Default:** `"global"`
- **Environment variable:** `MISTRAL_REGION`, used only when no config file sets `endpoint.region` (the value must be exactly `global`, `eu` or `us` — case-sensitive, no trimming)
- **Set with:** `/mistral set endpoint.region eu`

```json
{ "endpoint": { "region": "eu" } }
```

See [Use the EU or US region](/how-to/use-a-region/) · [Regions and data residency](/concepts/regions/)

### `endpoint.baseUrl`

An explicit API base URL for chat requests and the model catalog; wins over the region mapping.

- **Type:** string
- **Default:** unset (empty after trimming is unset)
- **Environment variable:** none
- **Set with:** `/mistral set endpoint.baseUrl https://gateway.example.com/mistral/v1`

```json
{ "endpoint": { "baseUrl": "https://gateway.example.com/mistral/v1" } }
```

The value supports the config-value protocol (`$VAR`, `${VAR}`, `!command`). See [Route requests through a gateway](/how-to/route-through-a-gateway/) · [Region routing](/reference/region-routing/)

## `connectorTools`

### `connectorTools.enabled`

Toggles the client-side connector tools loader.

- **Type:** boolean
- **Default:** `true`
- **Environment variable:** `MISTRAL_CONNECTOR_TOOLS`, used only when no config file sets `connectorTools.enabled` (`0`, `false` or `off`, case-insensitive, disables; any other non-empty value enables)
- **Set with:** `/mistral set connectorTools.enabled false`

```json
{ "connectorTools": { "enabled": false } }
```

See [Enable connectors and connector tools](/how-to/enable-connectors/)

### `connectorTools.autoLoad`

Connectors whose tools are registered and activated at session start.

- **Type:** array of strings (connector names)
- **Default:** unset
- **Environment variable:** none
- **Set with:** `/mistral set connectorTools.autoLoad notion` (comma-separated replaces; `+entry` appends, `-entry` removes, a bare key clears)

```json
{ "connectorTools": { "autoLoad": ["notion"] } }
```

A configured name that is not authenticated warns at session start; it is never skipped silently. See [Enable connectors and connector tools](/how-to/enable-connectors/)

## `models`

### `models.rateCard` <Badge text="Not settable via /mistral set" />

Per-family cost overrides for the model catalog, in USD per million tokens.

- **Type:** array of `{ "match": string, "rates": { "input": number, "output": number, "cacheRead": number, "cacheWrite": number } }`
- **Default:** unset (the built-in rate card applies)
- **Environment variable:** none
- **Set with:** not settable via `/mistral set` — hand-edit `mistral-native.json`

```json
{
  "models": {
    "rateCard": [
      {
        "match": "mistral-large",
        "rates": { "input": 0.7, "output": 2.1, "cacheRead": 0.07, "cacheWrite": 0 }
      }
    ]
  }
}
```

Entries are checked before the built-in card: the first entry whose `match` string is a substring of the model id applies, so a same-`match` entry shadows the built-in and new match strings work. A `match` of `""` prices the entire catalog and marks every cost approximate. See [Set your own prices](/how-to/set-your-own-prices/) · [Built-in rate card](/reference/rate-card/)

### `models.fallThrough`

Controls what unpriced models cost.

- **Type:** boolean
- **Default:** unset (effective `true`)
- **Environment variable:** none
- **Set with:** `/mistral set models.fallThrough false`

```json
{ "models": { "fallThrough": false } }
```

`false` gives models without a rate-card entry a zero-cost placeholder instead of the catch-all rates — still flagged approximate. See [Models and cost estimates](/concepts/models-and-costs/)

## `knowledge`

### `knowledge.streaming`

The streaming fallback for RAG queries when `rag.streaming` is unset.

- **Type:** boolean
- **Default:** unset (effective `true`)
- **Environment variable:** none
- **Set with:** `/mistral set knowledge.streaming false`

```json
{ "knowledge": { "streaming": false } }
```

Only `mistral_document_query` consumes this key. See [Query your documents](/how-to/query-your-documents/)

### `knowledge.searchModel`

The model the web-search and code-interpreter tools use for their calls.

- **Type:** string
- **Default:** `"mistral-small-latest"`
- **Environment variable:** none
- **Set with:** `/mistral set knowledge.searchModel mistral-small-latest`

```json
{ "knowledge": { "searchModel": "mistral-small-latest" } }
```

Model ids are not validated at load time; an unsupported one surfaces at use time. `mistral-large-4` refuses the builtin connectors of these calls with error 3004. See [Search the web](/how-to/search-the-web/) · [Run code with the code interpreter](/how-to/run-code-with-the-code-interpreter/)

## `rag`

### `rag.streaming`

Switches `mistral_document_query` between the streaming path and the legacy one-shot request.

- **Type:** boolean
- **Default:** `true`
- **Environment variable:** `MISTRAL_RAG_STREAMING` (`0`, `false`, `off` or `no` disable; `1`, `true`, `on` or `yes` enable), used only when neither `rag.streaming` nor `knowledge.streaming` is set in a config file
- **Set with:** `/mistral set rag.streaming false`

```json
{ "rag": { "streaming": false } }
```

See [Query your documents](/how-to/query-your-documents/)

### `rag.defaultLibraryId` <Badge text="Reserved" />

The default library for RAG queries.

- **Type:** string
- **Default:** unset
- **Environment variable:** none
- **Set with:** `/mistral set rag.defaultLibraryId lib-id`

```json
{ "rag": { "defaultLibraryId": "lib-id" } }
```

Reserved: validated and shown by `/mistral`, but no behavior derives from it.
