# Process Decision Records

This directory holds the **development-process** ADR series for
pi-mistral-native: decisions about how the project is developed —
platform, language, branching, testing, documentation and release
processes. Target-architecture decisions live one level up in
[docs/adr/](../README.md); the classification rules are
[0007](0007-adr-taxonomy.md).

The lifecycle is shared with the architecture series: records are born
`Trial`, promoted only by an explicit project-owner decision, immutable
once `Accepted` — see the architecture index for the full status legend.
